# Process

Create labels that do not exist yet.
Use the remote of the git repo as issue tracker.
If github is used use `gh` for accessing issues.

## Read open issues
- Read all open issues from the issue tracker

## Label issues
- Analyse the content of the story and label it according to the labelling instructions
- If the story is already triage-needed labelled check if the user added comment and adapt the story accordingly. If there are no follow-up questions remove the label.
- If more input of the user is needed add a comment adding questions for the user.

# Labeling instructions
- ready: this story is ready to be implemented
- triage-needed: this story needs more input from the user
- frontend: if this story concerns the frontend
- backend: if this story concerns the backend.
