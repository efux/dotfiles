---
description: Takes an issue and implement it
---

Take the issue with the number supplied with the skill call.
Load the issue with `gh`.
Make commits when a useful step is done.
After each commit make a push to the remote branch.
Make a plan for the implementation and execute it without user input.
Do all changes in a new branch in a new worktree
Ensure all the tests are passing.
Add new tests covering the happy case and some edge cases.
For the frontend make sure there is a Cypress test setup covering the acceptance criteria if possible.
Ensure coding guidelines are following and linting is successful.
Review your changes carefully yourself.
Push the branch to the remote and open a pull request. Reference the originating issue.
